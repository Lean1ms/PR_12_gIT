#  Zapret — обход блокировок DPI 

> *Краткое описание:* **Zapret** — это набор утилит для обхода систем глубокой инспекции пакетов (DPI). Программа восстанавливает доступ к заблокированным ресурсам без использования VPN-серверов и удалённых серверов — весь трафик обрабатывается локально на вашем компьютере.

## Описание программы

**Zapret** — это программный комплекс, который использует техники фрагментации пакетов, подмены TTL и других методов для обхода блокировок на уровне DPI. ~~Старые версии требовали ручной настройки правил брандмауэра~~. В новых сборках конфигурация упрощена за счёт готовых пресетов и графического интерфейса.

**Основные особенности:**
* Работа на уровне сетевого драйвера WinDivert 🖥️
* Поддержка Windows 10 и Windows 11 💻
* *Отсутствие необходимости в удалённом сервере* — всё работает локально
* Гибкая настройка через конфигурационные файлы ⚙️
* Запуск от имени администратора 🔑
